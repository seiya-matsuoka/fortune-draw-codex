# 要件

## 1. 開発目的

本開発の主目的は、Codex を利用した小規模な開発を通して、AI エージェントによる計画、実装、確認、修正の基本的な流れを体験することとする。

アプリ自体の高度さや機能量は重視せず、短いサイクルで Codex の操作に慣れることを優先する。

## 2. アプリ概要

ボタンを押すと、ランダムに選ばれた運勢と短いメッセージを表示する、1 画面構成のおみくじアプリとする。

## 3. 使用技術

- HTML
- CSS
- JavaScript

静的ファイルのみで構成し、外部ライブラリ、フレームワーク、パッケージマネージャー、ビルドツールは使用しない。

## 4. 機能要件

- おみくじを引くためのボタンを表示する。
- ボタンを押すと、定義済みの候補から運勢をランダムに 1 件選択する。
- 選択した運勢と、それに対応する短いメッセージを画面に表示する。
- ボタンは繰り返し押すことができ、その都度おみくじを引き直せる。
- 初期表示では、まだおみくじを引いていないことが分かる状態とする。

## 5. 運勢

少なくとも次の運勢を用意する。

- 大吉
- 中吉
- 小吉
- 吉
- 末吉
- 凶

各運勢の抽選確率は、特別な要件を設けず同じ確率としてよい。

## 6. UI 要件

- 1 画面で完結する。
- タイトル、おみくじを引くボタン、結果表示領域を持つ。
- PC とスマートフォンの一般的な画面幅で大きく崩れない。
- 小規模アプリに適した、シンプルで見やすいデザインとする。
- ボタンはキーボードでも操作できる標準的な HTML 要素を使用する。
- 結果更新が支援技術から認識できるよう配慮する。

## 7. 対象外

次の内容は本開発の対象外とする。

- ユーザー登録、ログイン、認証
- データ保存
- バックエンド
- データベース
- 外部 API
- 外部ライブラリ
- 複雑なアニメーション
- 複数画面、ルーティング
- 自動テスト環境の導入
- デプロイ

## 8. 完了条件

次を満たした状態を本開発の完了とする。

- `index.html`、`style.css`、`script.js` の静的構成で動作する。
- おみくじを引く操作で、定義済みの運勢とメッセージがランダムに表示される。
- 繰り返し操作しても正常に動作する。
- PC とスマートフォン相当の画面幅で主要 UI が利用できる。
- JavaScript の実行時エラーがない。
- 本要件および `docs/02-design.md` と実装内容が大きく矛盾していない。
